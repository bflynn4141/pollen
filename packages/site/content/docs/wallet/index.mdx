# Wallet Setup

You need a wallet to receive POLLEN tokens. Pollen supports three approaches:

| | Local encrypted EOA | Managed Wallet | Bring Your Own |
|---|---|---|---|
| **Setup** | One command on macOS | Email address | Existing 0x address |
| **Key management** | AES-GCM file + macOS Keychain | Handled by Para | You manage your keys |
| **Payouts** | Automatic to the address | Automatic to the address | Automatic to the address |
| **Portability** | Back up the encrypted file and Keychain | Any machine via email | Wherever you have the key |

## Quick setup

```bash
npx @pollen/cli wallet --local
```

The recommended beta path creates a standard EOA locally, encrypts its private
key before writing it to disk, and stores the separate wrapping key in macOS
Keychain. Only the address and contributor-binding signature reach Pollen.

Other wallet options remain available:

```bash
# Managed wallet
npx @pollen/cli wallet --email you@example.com

# Bring your own
npx @pollen/cli wallet --address 0x1234...abcd
```

Your wallet config is stored at `~/.pollen/config.json`.
The encrypted local wallet is stored separately at
`~/.pollen/local-wallet.json` with mode `0600`; neither file belongs in Git.
