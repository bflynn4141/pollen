# Quickstart

Get contributing in four steps. You need Node.js 20+ and a founding-panel invite.

<Steps>
<Step>
### Install the CLI

Install the beta from its public GitHub release:

```bash
npm install --global https://github.com/bflynn4141/pollen/releases/download/cli-v0.1.0-beta.1/pollen-cli-0.1.0-beta.1.tgz
```
</Step>
<Step>
### Join and install hooks

Join before setting up World ID so the server-issued pseudonymous identity is
the one you later verify:

```bash
pollen join <invite-code>
pollen setup
```

Setup preserves existing hooks. Capture stays local in `~/.pollen/local.db`.
</Step>
<Step>
### Inspect locally

After a completed agent session, inspect exactly what Pollen captured:

```bash
pollen my
```

This reads only your local SQLite database and performs no upload.
</Step>
<Step>
### Upload a network receipt

Sync only after inspecting your local data:

```bash
pollen sync
```

The client sends six coarsened fields. The server rejects prompts, arguments,
source, files, shell output, transcript paths, credentials, and unknown fields.
</Step>
</Steps>
