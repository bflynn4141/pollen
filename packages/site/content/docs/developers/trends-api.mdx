# Trends API Reference

Base URL: `https://pollen.dev/api/trends`

Most endpoints accept a `?period` query parameter:

| Value | Description |
|-------|-------------|
| `7d` | Last 7 days |
| `30d` | Last 30 days (default for most endpoints) |
| `90d` | Last 90 days |
| `all` | All time |

Default period is `30d` unless noted. `/satisfaction` defaults to `90d`, `/explore` defaults to `all`. `/heatmap` and `/autocomplete` do not accept a period parameter.

All responses include cache headers: `Cache-Control: public, max-age=300, stale-while-revalidate=600` (5-minute cache). Exception: `/autocomplete` uses a 1-minute cache (`max-age=60`).

## GET /overview

KPI summary — total prompts, sessions, tool events, top categories, and a daily sparkline.

```bash
curl "https://pollen.dev/api/trends/overview?period=30d"
```

```json title="Response"
{
  "totalPrompts": 14832,
  "totalSessions": 2341,
  "totalToolEvents": 48210,
  "avgSatisfaction": 4,
  "topTopic": { "name": "authentication", "count": 1205 },
  "topAction": { "name": "implement", "count": 4521 },
  "topTool": { "name": "Edit", "count": 12043 },
  "sparkline": [
    { "date": "2026-02-01", "count": 412 },
    { "date": "2026-02-02", "count": 387 }
  ]
}
```

Fields `avgSatisfaction`, `topTopic`, `topAction`, and `topTool` may be `null` when no data is available for the period.

## GET /topics

Topic distribution with time series. Each topic includes a total count and a daily/weekly series.

```bash
curl "https://pollen.dev/api/trends/topics?period=30d"
```

```json title="Response"
{
  "topics": [
    {
      "topic": "authentication",
      "total": 1205,
      "series": [
        { "date": "2026-02-01", "count": 42 },
        { "date": "2026-02-02", "count": 38 }
      ]
    }
  ]
}
```

## GET /tools

Tool usage ranking with success rates and trend indicators. Also includes MCP server breakdown and top tool time series.

```bash
curl "https://pollen.dev/api/trends/tools?period=30d"
```

```json title="Response"
{
  "tools": [
    {
      "tool_name": "Edit",
      "count": 12043,
      "success_rate": 94,
      "trend": "up",
      "changePercent": 12.5
    }
  ],
  "mcpServers": [
    { "mcp_server": "filesystem", "count": 3201, "success_rate": 98 }
  ],
  "topToolSeries": [
    {
      "tool_name": "Edit",
      "series": [{ "date": "2026-02-01", "count": 401 }]
    }
  ]
}
```

`success_rate` is a percentage (0–100), not a decimal.

## GET /sessions

Session workflow arcs (intent → outcome patterns) and recent session list.

```bash
curl "https://pollen.dev/api/trends/sessions?period=30d"
```

```json title="Response"
{
  "arcs": [
    { "intent": "implement", "outcome": "completed", "count": 842 },
    { "intent": "debug", "outcome": "resolved", "count": 531 }
  ],
  "recent": [
    {
      "session_id": "abc-123",
      "started_at": 1709251200000,
      "prompt_count": 12,
      "dominant_intent": "implement",
      "outcome": "completed",
      "satisfaction_score": 5
    }
  ]
}
```

Fields `dominant_intent`, `outcome`, and `satisfaction_score` in the `recent` array may be `null`.

## GET /heatmap

Activity by hour-of-day and day-of-week.

```bash
curl "https://pollen.dev/api/trends/heatmap?period=30d"
```

```json title="Response"
{
  "cells": [
    { "day": 1, "hour": 14, "count": 287 },
    { "day": 1, "hour": 15, "count": 312 }
  ],
  "maxCount": 312
}
```

`day` is 0=Sunday through 6=Saturday. `hour` is 0–23 UTC.

## GET /trending

Subjects gaining momentum right now.

```bash
curl "https://pollen.dev/api/trends/trending?period=30d"
```

```json title="Response"
[
  { "subject": "MCP servers", "count": 342, "growth": 85.2 },
  { "subject": "Tailwind v4", "count": 218, "growth": 42.1 }
]
```

`growth` is a percentage increase compared to the previous period. `null` if the subject is new.

## GET /explore

Deep-dive into a specific subject. Returns session count, time series, related subjects, and example sessions.

```bash
curl "https://pollen.dev/api/trends/explore?q=authentication&period=all"
```

**Required parameter:** `q` — the subject to explore.

```json title="Response"
{
  "query": "authentication",
  "totalSessions": 421,
  "series": [
    { "date": "2026-02-01", "count": 14, "normalized": 73 }
  ],
  "relatedSubjects": [
    { "subject": "JWT", "count": 89 },
    { "subject": "OAuth", "count": 67 }
  ],
  "sessions": [
    {
      "session_id": "abc-123",
      "started_at": 1709251200000,
      "subject": "authentication",
      "prompt_count": 8,
      "dominant_intent": "implement",
      "outcome": "completed"
    }
  ]
}
```

`normalized` is a percentage (0–100) relative to the peak count.

## GET /compare

Side-by-side comparison of multiple subjects.

```bash
curl "https://pollen.dev/api/trends/compare?items=React,Vue,Svelte&period=30d"
```

Accepts `?type=topics|actions|tools` (default: `topics`). Controls what dimension to compare across.

```json title="Response"
{
  "items": [
    {
      "name": "React",
      "total": 1842,
      "series": [{ "date": "2026-02-01", "count": 61 }]
    },
    {
      "name": "Vue",
      "total": 423,
      "series": [{ "date": "2026-02-01", "count": 14 }]
    }
  ]
}
```

```json title="Response"
  { "subject": "auth middleware", "count": 43 }
]
```

## Topics vs. subjects

The API uses two taxonomies. *Topics* (from `/topics`) are prompt-level classifications extracted from individual contributions. *Subjects* (from `/trending`, `/explore`, `/autocomplete`, `/compare`) are session-level classifications that describe what the overall session was about. They may use different vocabularies.
