# API Reference

The current endpoint contract, sample responses, prices, privacy behavior, and production-origin status are maintained on the [Aggregate API page](/docs/api).

Use `GET /catalog` for a machine-readable contract:

```bash
curl https://pollen-api.bflynn4141.workers.dev/catalog
```

All published cells require at least five distinct contributors. Pollen does not expose raw prompts, raw sessions, or arbitrary queries.
