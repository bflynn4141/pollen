# For Developers

Pollen aggregates anonymized prompt intelligence from thousands of Claude Code sessions into a queryable API. Use it to understand how developers actually use AI coding tools.

## What's available

The [Trends API](/docs/developers/trends-api) exposes 13 endpoints covering:

- **Topics** — what developers work on (authentication, databases, UI, etc.)
- **Tools** — which Claude tools get used and how often they succeed
- **Models** — which AI models are in use
- **Commands** — CLI command frequency
- **Sessions** — how coding sessions flow from intent to outcome
- **Satisfaction** — are developers happy with their AI interactions?
- **Heatmap** — when do developers code?
- **Trending** — what subjects are gaining momentum right now
- **Explore** — deep-dive into any subject with related topics and session examples

All endpoints return JSON with 5-minute cache headers.

## Access

The Trends API is publicly accessible at:

```
https://pollen.dev/api/trends/*
```

For high-volume access, queries are priced via [x402 micropayments](/docs/developers/x402) — pay per request with no API keys or subscriptions.
