# For Developers

Pollen offers aggregate signals about coding-agent models, public MCP usage, tool categories, coarse intents, workflows, and observable outcomes. It does not provide raw prompts or individual session records.

Start with the free product catalog and network preview:

```bash
curl https://pollen-api.bflynn4141.workers.dev/catalog
curl https://pollen-api.bflynn4141.workers.dev/network
```

Use free endpoints to evaluate coverage and freshness. Use paid endpoints for full published history. Payment uses x402 v2 and USDC on Base, with no API key required for reads.

- [Data Catalog](/docs/developers/catalog): fields, provenance, freshness, and prices
- [API Reference](/docs/api): endpoint contracts and below-threshold behavior
- [Use Cases](/docs/developers/use-cases): appropriate uses and limits
- [x402 v2](/docs/developers/x402): payment integration
